# Hello World in C

My first C program that prints **"Hello, World!"** to the screen.

## Code

```c
#include <stdio.h>

int main()
{
    printf("Hello, World!");
    return 0;
}
```

## Output

```text
Hello, World!
```

## What I Learned

* Basic structure of a C program
* Using `#include <stdio.h>`
* Using the `main()` function
* Printing text using `printf()`
* Using `return 0;`

## Language

**C**
